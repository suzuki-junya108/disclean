安全のしくみ

消す前に、戻せるようにしてから消します。

ディスクリンが「削除」と呼ぶ操作は、同じディスクの中で場所を移すことです。実際に消えるのは、そのあとです。

  1. 01 うつす

    瓶に入れる

    選んだものは同じディスク内の隔離庫へ移ります。容量によらず一瞬で終わります。

  2. 02 まつ

    7日おいておく

    既定で 7 日。1〜90 日に変えられます。この間は元の場所へそのまま戻せます。

  3. 03 もどす

    掴んで戻す

    disclean undo か、瓶から掴み出すだけ。戻したバイト数が一致することを確認します。

  4. 04 のこす

    記録が残る

    移動・復元・完全削除を 1 件ずつ記録します。記録できないときは、削除自体を行いません。

    区分 C

    ディスクリンが触らないもの。

    取り戻せないもの、取り直すのに時間がかかるものには、削除の機能そのものを作っていません。大きさは見せますが、消すのはあなたの手です。

    • ゴミ箱の中身測定にはフルディスクアクセスが必要 Finder から空にしてください。
    • Xcode のアーカイブ大きさだけ見せます 配布済みアプリの dSYM が入っています。消すとクラッシュの原因が読めなくなります。
    • Docker の名前付きボリューム— データベースの中身が入っていることがあります。ディスクリンの prune はボリュームに触れません。
    • ollama・Hugging Face・whisper のモデル数十 GB になりがち 再取得に時間と帯域がかかります。キャッシュという名前でも、消して安いものではありません。
    • iOS デバイスのバックアップ測定にはフルディスクアクセスが必要 Finder のデバイス画面から管理してください。
    • システム領域（/System, /Library, /private/var）— ディスクリンは sudo を使いません。あなたのホームの外には出ません。

    よくある質問

    先に答えておきます。

    本当に元に戻せますか？

    ディレクトリを移す種類の片づけは戻せます。既定で 7 日、disclean undo で元のパスに戻します。ただし brew cleanup や npm cache clean のように外部ツールに実行を任せるものは戻せません。実行前の確認画面で「これは取り消せません」と表示します。

    sudo は必要ですか？

    使いません。ディスクリンはあなたのホームディレクトリの外に出ません。システム領域は大きさを見せるだけで、削除の機能を持ちません。

    何かデータを送信しますか？

    あなたのファイルの情報は送りません。スキャンの結果・ファイルの場所・片づけた量は、すべて手元のディスクにだけ残ります。通信するのは掃除ルールの更新を取りに行くときだけで、そのとき相手（GitHub）に伝わるのは、ディスクリンのバージョンと macOS のバージョンだけです。接続元の IP アドレスと時刻は、どんな通信でも相手側の記録に残ります。このページも解析ツールを置いていません。

    更新はどうやって届きますか？ 止められますか？

    macOS が新しくなるとキャッシュの置き場所が変わることがあるため、掃除ルールだけを署名付きで配っています。ディスクリンは 1 日 1 回、実行したときにだけ確認します（常駐しません）。受け取ったルールは、署名を確かめたうえで、消す対象が増える変更なら必ずあなたの承認を待ちます。承認するまで消えるものは 1 つも増えません。止めるときは disclean update --off（または DISCLEAN_AUTO_UPDATE=0）で、以後は通信そのものが発生しません。アプリ本体は自動で入れ替えず、新しい版があることをお知らせするだけです。

    消したのに空き容量が増えません。

    隔離庫は同じディスクの中にあるため、7 日たつまでは容量が戻りません。すぐ空けたいときは disclean purge を実行してください。Time Machine のローカルスナップショットが残っている場合も、反映が遅れることがあります。

    やめるときはどうしますか？

    disclean purge --all で隔離庫を空にし、brew uninstall disclean と、状態フォルダ ~/.local/state/disclean の削除で終わりです。記録を残したい場合は audit/ だけ退避してください。
