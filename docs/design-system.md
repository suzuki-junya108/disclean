## 1. デザインの主張（Thesis）

**「ギガバイトには重さがある」。**

disclean が扱うものは数値ではなく質量である。44.3GB のシミュレータは表の 1 行ではなく、持ち上がらない塊だ。だから disclean の UI では、容量が**物理的な塊（チャンク）**として画面上に存在し、実行レバーを引くと**瓶（隔離庫）に落ちる**。7 日間はそこに沈んでいて、掴んで引き戻せる。

この物理性が、POP と安全性を同時に満たす。ポップさは色と質感と動きが担い、**安全に関わる情報（何を失うか・取り消せるか）だけは一切くずさない**。

### 1.1 やらないこと（このデザイン言語の禁則）

| 禁則 | 理由 |
|---|---|
| グラデーション（背景・ボタン・テキストすべて） | ベタ塗り＋黒キーラインで「刷り物」の質感を出す。グラデーションはその質感を壊す |
| ぼかし影（`blur > 0` の `box-shadow`） | 影は必ずハードオフセット（`Npx Npx 0`）。ステッカーの浮きを表現する |
| グラスモーフィズム / 半透明ブラー | 同上 |
| マスコットキャラクター | 「1つアクセサリーを外す」。物理性（チャンク・レバー・瓶）に集中する |
| 紙吹雪・キラキラの成功演出 | 削除ツールの完了は祝う場面ではない。落下と着地の「ドスッ」だけで足りる |
| リスク情報のポップ化 | 「何を失うか」「取り消せるか」は装飾せず、常に本文サイズ・地の色・最高コントラストで書く |
| 危険操作をワンクリックにすること | レバーの引き下ろし（またはキーボードの明示操作）を必須にする |

## 2. カラートークン

### 2.1 パレット定義

| トークン | 値 | 役割 |
|---|---|---|
| `--ink` | `#16121F` | 文字・キーライン・影。純黒ではなく茄子寄りの黒 |
| `--paper` | `#FFF2DC` | カード地・明色文字 |
| `--void` | `#100D18` | ダークモードの地 |
| `--lime` | `#C6F833` | **Tier A**（既定選択・安全） |
| `--sunbeam` | `#FFD23F` | **Tier B**（要確認） |
| `--sky` | `#4CD8FF` | **Tier C**（表示のみ・情報） |
| `--grape` | `#6C2BEA` | 実行レバー・復元（undo）。唯一の反転色 |
| `--tomato` | `#FF4A32` | 失敗・エラーのみ |
| `--bubblegum` | `#FF6FB5` | LP の見出しアクセント。GUI では状態を表さない装飾のみ |

### 2.2 文字色の決定規則（実測コントラスト比）

| 地 | 文字 | 比 | 判定 |
|---|---|---|---|
| `--paper` | `--ink` | 16.65 | AAA |
| `--void` | `--paper` | 17.37 | AAA |
| `--lime` | `--ink` | 14.80 | AAA |
| `--sunbeam` | `--ink` | 12.75 | AAA |
| `--sky` | `--ink` | 11.03 | AAA |
| `--bubblegum` | `--ink` | 7.18 | AAA |
| `--tomato` | `--ink` | 5.50 | AA |
| `--grape` | `--paper` | 5.99 | AA |

**規則**: 明色チップ（lime / sunbeam / sky / bubblegum / tomato）の上は必ず `--ink`。`--grape` の上は必ず `--paper`。**この 2 通り以外の組み合わせを作らない**。彩色どうしの重ね（例: lime の上に sky の文字）を禁止する。

### 2.3 ダークモード

地を `--void` に、カード地を `#1C1726`、キーラインと影を `--paper` に反転する。キャンディ 6 色は**値を変えない**（`--void` 上でのコントラストは lime 15.44 / sunbeam 13.31 / sky 11.51 / bubblegum 7.50 / tomato 5.74 で全て AA 以上）。`--grape` はダークでは地として使わず、`--paper` のキーラインを持つ塗りとしてのみ使う。

### 2.4 Tier と色の対応は不変

Tier → 色の対応（A=lime / B=sunbeam / C=sky）は**色だけで伝えない**。必ずチップ内に文字（`A` / `B` / `見るだけ`）を併記する（§8.8 の要件）。色覚特性による判別不能を前提とした設計とする。

## 4. 形と質感

| 要素 | 仕様 |
|---|---|
| 角丸 | カード 22px / チップ 999px（ピル）/ チャンク 14px。**中間値を作らない**（この 3 つのみ） |
| キーライン | 全要素 `3px solid var(--ink)`（ダークは `var(--paper)`）。線幅は 3px 固定、細線を使わない |
| 影 | `6px 6px 0 var(--ink)`（カード）/ `4px 4px 0`（チップ・ボタン）。**ぼかし 0 固定** |
| 回転 | ステッカー感のため `-2deg`〜`+2deg` をカードに付与。**同一列で同じ角度を繰り返さない**（連番 index の剰余で -2 / +1.5 / -1 / +2 を巡回） |
| 区切り | セクション境界は直線ではなく**破線カット**（SVG の三角波、振幅 12px・周期 28px） |
| 地の質感 | ハーフトーン網点（`radial-gradient` ではなく 4px 間隔の SVG パターン、不透明度 0.06、`--ink` 単色） |

> 注: 地の網点は SVG パターンで実装する。§1.1 の「グラデーション禁止」は塗りの表現に対する禁則であり、網点テクスチャはこれに含まれない。

## 5. シグネチャー要素

### 5.1 チャンク（容量の塊）

- 1 ルール = 1 チャンク。**高さが容量に比例**する: `height = clamp(48px, 48px + GB * 3.2px, 320px)`。
- 面はその Tier の色、キーライン 3px、影 4px。上面に容量（Data 書体 32px）、下にルール名（Body 15px）。
- **チャンク上には必ず「失うもの」を 1 行で置く**（Caption 12px、装飾なし、地の色の文字）。
- 積み上げ表示（タワー）と一覧表示（リスト）を切り替えられる。既定はタワー。

### 5.2 レバー（実行）

- 画面右下に固定された縦 220px のレバー。`--grape` の握り＋ `--ink` の軸。ラベルは Display 800 で「ひきさげて実行」。
- **クリックでは発火しない**。握りを 120px 以上ドラッグして離すと実行される。途中で離すとバネで戻る。
- キーボード操作: レバーに `role="button"` と `tabindex` を与え、フォーカス時に `Space` 長押し 800ms または `Enter` → 確認シートで実行。**マウスなしで必ず完了できること**。
- レバーが引かれると、選択中のチャンクが順に瓶へ落下する（`--reduced-motion` 時は落下せず、瓶の中に即時出現する）。

### 5.3 瓶（隔離庫）

- 画面下部の透明な瓶。中に隔離中のチャンクが積もる。瓶の口に**残り日数のリング**（7 日を 1 周とする円弧、`--ink` 3px）。
- チャンクは失効が近づくと網点の密度が上がる（7 日: 0.06 → 1 日: 0.24）。**色は変えない**（色で危険を伝えない原則）。
- 瓶からチャンクを掴んで外へドラッグ = 復元（undo）。ドラッグ中の握りは `--grape`。

### 5.4 数字の字面が重くなる（LP のシグネチャー）

容量そのものを型で表す。Martian Mono の可変軸 `wdth`（75〜112.5）を数値に割り当て、**大きい数ほど字面を広げる**。
ヒーローのメーターは瓶に入れた量に応じて `wdth 82 → 112` を線形に動かし、見出しは 1 行目 `wdth 84` / 2 行目 `wdth 100` として、
「重さで見せます」の行そのものを重くする。色や装飾を足さずに、数の大小を文字の物理量として見せるための仕掛け。

### 5.5 LP のヒーロー

ヒーローは製品の約束そのものを 3 秒で見せる。実測値（本ドキュメント作成マシンの CoreSimulator 71.5GB / Docker 26.6GB / `~/.cache` 9.7GB）を積んだタワーが立っており、訪問者は**そのままレバーを引ける**。落ちたチャンクは瓶に溜まり、掴んで引き戻せる。これがそのまま「消しても 7 日は戻せる」の説明になる。

## 6. モーション

**塊は硬い箱ではなく、重いグミである。** 押せば潰れ、離せば行き過ぎてから揺れて止まる。
「ギガバイトには重さがある」を、色と形だけでなく動きでも言う。

### 6.1 動きの語彙

| 名前 | 何を言うか | 実装 |
|---|---|---|
| `jelly` | 押した手応え。横に膨らみ縦に潰れ、揺れて戻る | LP: `@keyframes jelly` / GUI: `.jelly(on:)` |
| `plop` | 上から落ちて着地する。着地でひしゃげる | LP: `@keyframes plop` / GUI: `.plopIn(index:)` |
| `wobble` | 中身が入って器が揺れる（瓶） | LP: `@keyframes wobble` |
| `shudder` | 落下の衝撃が土台に伝わる（置き場） | LP: `@keyframes shudder` |
| `breathe` | 静かに息をする。**押せない飾りにだけ**使う | LP: `@keyframes breathe` |

曲線は `--gummy: cubic-bezier(0.22, 1.4, 0.36, 1)`（行き過ぎてから戻る）。
GUI は `Motion.gummy` / `Motion.squishy` / `Motion.drop`（`spring`, dampingFraction 0.42〜0.6）。

### 6.2 どこで動かすか

| 動き | 仕様 |
|---|---|
| 塊の登場 | 下から順に `plop`。1 つあたり 60〜70ms ずらす。全体 900ms 以内 |
| 塊を選ぶ | `jelly`（横 +8% / 縦 −8% → 揺れて戻る） |
| 塊に触れる | `translate(-2px,-2px)` ＋ わずかに横へ伸びる。120ms |
| 塊を押している間 | 縦に伸びて横に縮む（潰れる）。離すと揺れて戻る |
| レバー | 引くほど握りが縦に伸びる（最大 +10%）。離すと `--gummy` で戻る |
| 実行 | 置き場が `shudder`、瓶が `wobble`、粒が `plop` で着地 |
| 復元 | 戻した塊がタワーの中で `jelly`、瓶が `wobble` |
| 画面の切り替え（GUI） | 縮小 2% ＋ 不透明度のかけ合わせ。`Motion.gummy` |
| 数値の変化（GUI） | 桁が入れ替わり、枠が `jelly` する |
| ブロック壁（LP） | 画面に入ったら 9ms 間隔で `plop`。一度だけ |
| ベルトコンベア（LP） | 34 秒で 1 周。等速 |
| 息づかい | 瓶とブランドマークだけ。**押せる要素には付けない** |
| `prefers-reduced-motion: reduce` / `accessibilityReduceMotion` | 上記すべてを無効化し、状態変化は 0ms で反映する。**レバーのドラッグ要件も解除**し、単一クリック＋確認シートに切り替える |

### 6.3 動かさないもの（禁則）

- **押せる要素を常時動かさない**。クリックの的が動き続けると狙いづらく、目も休まらない
  （実測でも、自動テストが「要素が静止しない」と判定してクリックできなくなった）
- 「何を失うか」「取り消せるか」「触らないもの」の文字は動かさない（§1.1）
- 成功を祝う演出（紙吹雪・キラキラ）を足さない。落下と着地の手応えで足りる
- 動きは `transform` と `opacity` だけで作る（再描画を起こさない）

## 7. コンポーネント仕様

| コンポーネント | 構造 | 状態 |
|---|---|---|
| Tier チップ | ピル、`3px` キーライン、Label 書体、文字は `A` / `B` / `見るだけ` | 静的 |
| チャンク | §5.1。選択時はキーラインが 5px に太り、影が `8px 8px 0` に伸びる | 選択 / 非選択 / 無効（`blocked`）/ 落下中 |
| `blocked` チャンク | 面を `--paper`、キーラインを破線 3px、上に理由（例「フルディスクアクセスが要ります」） | 静的。**選択できない** |
| 確認シート | カード、`--paper` 地、対象一覧＋合計＋失効日時。「これは取り消せません」は `--tomato` の帯に `--ink` 文字 | 通常 / command 型（取り消し不可の警告あり） |
| 空状態 | 瓶だけが置かれ、「片づけるものはありません」＋再スキャンボタン | 静的 |
| エラー | `--tomato` 帯 ＋ 対象パス（Data 書体）＋ 直せる手順 | 静的 |
| フォーカスリング | `outline: 3px solid var(--grape); outline-offset: 3px`。ダークでは `--sky` | 全対話要素で可視 |

## 9. 実装規約

| 項目 | GUI (SwiftUI) | LP (HTML/CSS) |
|---|---|---|
| トークンの持ち方 | `DesignTokens.swift`（`Color` / `Font` / `CGFloat` の静的定数） | `:root` の CSS カスタムプロパティ |
| ダーク切替 | `@Environment(\.colorScheme)` | `:root` に明色を定義し、`@media (prefers-color-scheme: dark)` と `:root[data-theme="dark"]` の両方で上書き |
| 影 | `.shadow` は使わない（ぼかしが入るため）。オフセットした矩形を重ねて描く | `box-shadow: Npx Npx 0` |
| モーション低減 | `@Environment(\.accessibilityReduceMotion)` | `@media (prefers-reduced-motion: reduce)` |
| 単位 | pt 固定値（Dynamic Type には `@ScaledMetric` で追従） | `rem` 基準、コンテナ幅は `clamp()` |
| 外部リソース | フォントを同梱。ネットワーク取得を行わない | Google Fonts のみ許可。他の外部ホストを参照しない |

## 10. 受け入れ基準（デザインの検証可能な条件）

| ID | 条件 | 検証方法 |
|---|---|---|
| D-01 | 全テキストのコントラスト比が 4.5:1 以上（Label / Caption 含む） | LP: axe-core の `color-contrast` が 0 violations。GUI: §2.2 の組み合わせ表以外が使われていないことを `DesignTokens` の単体テストで検証 |
| D-02 | `blur` を含む影が 1 つも存在しない | LP: ビルド後の CSS を `grep -E 'box-shadow:[^;]*[0-9]+px [0-9]+px [1-9]'` して 0 ヒット。GUI: `.shadow(` の使用を SwiftLint のカスタムルールで禁止 |
| D-03 | `linear-gradient` / `radial-gradient` が塗りに使われていない | LP: CSS を grep して 0 ヒット（SVG パターン定義を除く） |
| D-04 | Tier が色のみで表現されていない | 全 Tier チップに文字ラベルが存在することを XCUITest / DOM テストで検証 |
| D-05 | レバーがキーボードのみで操作でき、フォーカスが可視 | XCUITest（GUI）/ Playwright のキーボード操作（LP） |
| D-06 | `prefers-reduced-motion` 有効時にレバーのドラッグ要件が単一クリックに切り替わる | Playwright でメディア特性を強制して検証 |
| D-07 | 360px 幅で LP が横スクロールしない | Playwright で `document.documentElement.scrollWidth <= window.innerWidth` |
| D-08 | LP がフォント以外の外部ホストへ通信しない | Playwright のネットワークログに `fonts.googleapis.com` / `fonts.gstatic.com` 以外の外部ホストが出ない |
